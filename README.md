# 🌡️ Temperature Converter

A simple and responsive **Temperature Converter** built using **HTML, CSS, and JavaScript**. This web application allows users to convert temperature values between **Celsius, Fahrenheit, and Kelvin** with an easy-to-use interface.

---

## 📌 Project Overview

The Temperature Converter is designed to provide quick and accurate temperature conversions. Users can enter a temperature value, choose the input unit and the desired output unit, and instantly view the converted result.

---

## ✨ Features

- Clean and Responsive User Interface
- Convert Celsius to Fahrenheit
- Convert Celsius to Kelvin
- Convert Fahrenheit to Celsius
- Convert Fahrenheit to Kelvin
- Convert Kelvin to Celsius
- Convert Kelvin to Fahrenheit
- Input Validation
- Instant Temperature Conversion
- Mobile-Friendly Design

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open **index.html** in your preferred web browser.
4. Enter a temperature value.
5. Select the input and output units.
6. Click the **Convert** button to view the result.
